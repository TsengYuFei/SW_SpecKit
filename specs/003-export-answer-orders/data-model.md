# Data Model: 結果匯出與教師收件順位

本文件為設計與實作對照：Phase 2共同順位與readSnapshot、Phase 3 CSV／下載模型已完成；Phase 4已建立AnswerOrderPanel及HistoryLive，Copy仍待Phase 5。本階段交付門檻依tasks.md追蹤。既有SQLite 17表／110欄不變，不新增migration或永久實體。模型受 [spec.md](spec.md)、[research.md](research.md) 及 [介面契約](contracts/interfaces.md) 約束。

## Existing Persistence Sources

| 實體／既有欄位                                                                        | 本功能用途與限制                                                                                                                                     |
| ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| activities.id、owner_account_id、phase、revision、group_count、next_sequence          | 單一UUID、owner限定、ended才下載；group_count是全部預設組數，ordinal恰為1..group_count。N筆受理sequence恰為1..N，next_sequence=N+1，拒絕整筆受理遺失 |
| activities.spreadsheet_title、source_snapshot_json、source_fingerprint                | 活動名稱取建場source.spreadsheetTitle；先預檢快照bytes再解析；title與快照、fingerprint及正規化題目須一致，雲端改名不影響                             |
| questions.activity_id、question_id、display_number、kind、ordinal                     | 依ordinal及保存快照順序輸出，不把display_number改成數字排序                                                                                          |
| question_items.activity_id、question_id、item_id、ordinal、label、prompt              | 子題順序與原文字；須與快照中的完整item集合相符，空label才以item位置補標籤                                                                            |
| activity_groups.activity_id、id、ordinal、participant_id、name                        | 全部組別均讀取；participant_id只供內部occupied判斷，不進導出模型或下載；未加入name映成空字串、只顯組號                                               |
| submissions.activity_id、id、group_id、question_id、request_id、received_at、sequence | 首次已受理答案；sequence為唯一共同先後，received_at僅既有顯示資料，不用來破同順位                                                                    |
| submission_answers.activity_id、submission_id、question_id、item_id、answer           | 每筆受理須精確包含該題所有item，答案不得缺漏或以空值補齊                                                                                             |
| results.activity_id、question_id、winner_submission_id                                | ended每題固定結果須存在，並與共同sequence最早受理相符；匯出包含所有受理，不只winner                                                                  |

不讀participants的browser_token_digest，不讀OAuth／session原值，不依writeback_jobs／attempts／Google讀取來生成CSV。回填pending／conflict／failed不妨礙有效結果下載；無權限與不存在活動同回ACTIVITY_UNAVAILABLE。

## Planned Transient Entities

以下欄位是記憶體值／導出模型，**不新增DB表或Socket wire欄位**。

### AnswerOrderInput

| 欄位                                  | 型別／驗證                                                                                 |
| ------------------------------------- | ------------------------------------------------------------------------------------------ |
| questions                             | readonly陣列；id為唯一非空題目識別、displayNumber、kind(single/group)、items依保存順序     |
| questions[].items                     | id在該題唯一；label、prompt沿用已保存文字；每題至少1項，single須恰有1項                    |
| groups                                | readonly陣列；id為唯一UUID、ordinal為唯一正安全整數、name、occupied；涵蓋全部預設組別      |
| groups[].name                         | occupied=true時去首尾空白後1–40 UTF-16且與已保存值一致；未加入為空，不合成名稱             |
| submissions                           | 必須明確提供陣列，沒有答案為[]；不把缺少teacher submissions屬性默認空陣列                  |
| submissions[].id／groupId／questionId | submission UUID唯一，group／question必須存在且group已加入；同組同題最多1筆                 |
| submissions[].sequence                | 唯一正安全整數，沿用原值且排序後恰為1..N，不重新編全場序號；收到時間相同不影響排序         |
| submissions[].answers                 | itemId→原答案，key集合精確等於該題items，值符合既有非空及2000 UTF-16上限；不得額外增刪答案 |

輸入可由teacher ActivitySnapshot／HistoryDetail.snapshot取既有欄位，backend結果讀取器亦產生同型。純函數不能修正損壞資料或突變輸入；會先驗結構，再建立結果。UI攔截錯誤顯示該區「作答紀錄無法完整顯示」，保留其他頁面操作，不將例外直接拋出React render。

### OrderedAnswer

| 欄位                | 型別／語意                                                                       |
| ------------------- | -------------------------------------------------------------------------------- |
| submissionId        | 已受理提交UUID，只供UI key／交叉驗證，不寫CSV                                    |
| questionId／groupId | 指向Input題目與組別，不進CSV表頭                                                 |
| fullGroupName       | 既有fullGroupName formatter結果，例第1組-甲組；不截長名、不因CSV例子空格另存別名 |
| globalSequence      | 原submissions.sequence，畫面標「全場收件序號」                                   |
| questionRank        | 本題entries中的index+1，連續1..A，畫面標「本題搶答順位」                         |
| items               | 按原題items順序的itemId／label／prompt／answer，不依answers物件key排序           |

### QuestionOrder

| 欄位                                   | 型別／語意                                                                                                      |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| questionId、displayNumber、kind、items | 與Input相同題目識別／順序／文字                                                                                 |
| entries                                | OrderedAnswer[]，依globalSequence遞增；題組共用這一份順位                                                       |
| unansweredGroups                       | {groupId, ordinal, fullGroupName}[]；全部groups減本題entries組別，依ordinal遞增；未加入name為空因此只顯系統組號 |

`AnswerOrderView`為`{all:OrderedAnswer[], questions:QuestionOrder[]}`。all依globalSequence排序、questions依教材順序。每題entries數A加unansweredGroups數U等於groups.length；所有entries第1筆須與原固定winner一致，不修改原winner。

### ExportSnapshot

| 欄位         | 型別／語意                                                                  |
| ------------ | --------------------------------------------------------------------------- |
| activityId   | 完整UUID，不截短                                                            |
| activityName | 建場保存的source.spreadsheetTitle，可空但型別須為字串；不能從當下Google重讀 |
| phase        | 必須ended                                                                   |
| revision     | 非負安全整數，表示本次唯讀快照；不因下載增加                                |
| groupCount   | 與groups.length一致，涵蓋未加入組別，ordinal恰為1..groupCount               |
| order        | 驗證後AnswerOrderView                                                       |
| exportedAt   | 開始處理時一次擷取UTC epoch ms，僅檔名轉Asia/Taipei，不寫DB                 |

ExportSnapshot另包含內部nextSequence正安全整數，必須等於order.all.length+1；即使遺失的是最後一筆非winner提交，仍須回STORAGE_CORRUPT，不能把原作答組別補成未作答。此欄不新增到HTTP JSON或Socket wire。

ownerAccountId、session及authGeneration保留於後端請求scope，用於開始與送出前核權限，**不屬於CSV或對外metadata**。snapshot讀取在BEGIN DEFERRED內完成，釋放後才讓出事件迴圈編碼。readSnapshot保存原query_only並暫設ON，finally恢復原值；與寫交易旗標互斥，不得巢狀、不得Promise、不得寫入或註冊afterCommit。失敗ROLLBACK且恢復連線狀態。此helper要有正常／拋錯／寫入拒絕／原query_only恢復／巢狀／非同步回傳測試。

### CsvLayout and DownloadArtifact

| 欄位         | 型別／規則                                                                            |
| ------------ | ------------------------------------------------------------------------------------- |
| dataRowCount | single數＋所有group items數；整數且>0                                                 |
| aMax／uMax   | 分別為全題最大A／U，均可0；不是同一題也合法                                           |
| columnCount  | 3+2×aMax+2×uMax；所有資料列及表頭一致                                                 |
| headers      | 固定題號／子題／題目，其後每rank成對，再每未作答位置成對；字串精確依spec              |
| cellText     | 一般原文字；危險前綴才加單一TAB的excel-tab-v1顯示值，DB原值不變                       |
| row          | 題號、單題空子題／題組label、prompt及固定layout各對值；缺rank／未作答slot為兩個空字串 |
| bytes        | UTF-8，僅起始EF BB BF一次，全欄quoting、雙引號加倍、CRLF記錄結尾；不是JSON            |
| filename     | 合法完整下載名稱，依contracts檔名規則                                                 |
| contentType  | text/csv; charset=utf-8                                                               |

子題label明確規則：純外層全形或半形括號剝一層，例如（1）或(1)→1；非裝飾文字保留。空label或剝除後空字串以原item位置1起編號；single固定空。所有字串在安全文字處理後、quoting前檢查cell上限；字元計數採UTF-16 code units。CSV bytes上限包含BOM及轉義增加的bytes。

## Bounds and Failure Rules

唯一數值來源為 [research R4](research.md#r4-有界匯出與完整性) 所列EXPORT_LIMITS；實作時集中backend/export/limits.ts。Excel含表頭列／欄／cell字數／LF及專案logical cells／raw input／output bytes上限任一超過即EXPORT_TOO_LARGE，不裁切資料。只有檔名的活動名稱段可以依預算縮短，題目／答案／組名不能為了下載而縮短。

資料結構、集合、來源對照、groupCount或frozen winner不一致，回STORAGE_CORRUPT；暫時讀取失敗回STORAGE_UNAVAILABLE；等待／active回INVALID_PHASE。輸出逾時或資源slot已占用回EXPORT_BUSY，頻率超限RATE_LIMITED；上述失敗不帶CSV attachment，不改DB。

## UI Operation State Transitions

| 操作             | 狀態及轉移                                                                                                  | Scope失效                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Download         | idle→loading→started或error；started僅表示瀏覽器下載已啟動，不代表已存磁碟；loading停用重複點擊，不自動重試 | AbortController取消fetch／body，遞增epoch、清理objectURL；舊結果不得觸發anchor或回饋 |
| Copy             | idle→pending→copied或error；pending停用重複操作；無clipboard立即error並保留可選URL                          | 不能撤回已交給瀏覽器的write；不再主動寫舊URL，忽略舊resolve／reject                  |
| AnswerOrderPanel | 全部收件或依題目視角＋selectedQuestionId；預設全部收件，切逐題預選第一題                                    | activityId／boot／sessionVersion／authGeneration變化重設視角與選題，不帶舊答案       |
| History live     | waiting/active詳情→subscribe原場；收到ended→保存該snapshot並一次重讀detail；舊場非current→一次重讀保存狀態  | 卸載、切帳號取消及拒收舊回覆；不輪詢重試迴圈，不為讀取重建活動                       |

這些狀態均非新增活動階段；原waiting→active→ended與worker狀態機不變。

Phase 4實作中，AnswerOrderPanel.view使用all／question並以selectedQuestionId選題；activity／boot／sessionVersion／authGeneration的外層key變更會重新建立面板。HistoryLive.state使用live／refreshing／saved，分別對應原場訂閱、唯一一次保存資料同步、保存快照；初始ended直接saved不訂閱。useActivity新增的本機errorCode只辨別ACTIVITY_UNAVAILABLE與暫時連線錯誤，不增加Socket欄位；JSON helper可選AbortSignal以取消舊歷史請求。
